# Sprint_5

Проект содержит UI-автотесты, покрывающие пользовательские сценарии (Регистрация, Авторизация и Публикация объявлениями).

## Стек технологий
* Python 3
* Pytest (тестовый фреймворк)
* Selenium WebDriver (управление браузером Chrome)

## Тест-кейсы в покрытии
1. **Регистрация**: Позитивный сценарий, валидация некорректного email, проверка регистрации дубликата.
2. **Авторизация**: Вход пользователя в систему (Login) и выход (Logout).
3. **Объявления**: Ограничение доступа к созданию для неавторизованных пользователей и успешная публикация от имени авторизованного пользователя.

## Команда для запуска
Для запуска всех тестов из корня проекта выполните:
```bash
python3 -m pytest tests/ -v
